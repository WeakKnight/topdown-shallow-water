# 实现与渲染说明

安装、操作和视频录制见 [README](../README.md)。

## 双足动画与交互

Y 轴朝上，水面静止高度为 0。默认水深 0.12 m，岸边 0.35 m 范围内平滑变浅；水底高度同时用于程序化落脚位置和水体着色。每只脚用有朝向的椭球代理，宽 0.20 m、长 0.44 m、高 0.18 m，尺寸有意适度放大以便在 MOBA 镜头下观察。

`gait.py` 只生成动画，不求解水面：

1. 根据角色移动速度和方向确定左右脚下一落点。
2. 支撑脚锁定世界坐标，另一只脚沿抬起、平移、下降的轨迹摆动。
3. 步频随速度增加，并有最小步频限制，避免高速、低步频组合导致过长跨步。
4. 停步后完成当前摆动，必要时补一步，把两只脚收回角色附近。
5. 每个模拟子步提交所有脚的上一位置、当前位置、朝向、尺寸与调试状态。

`shaders/feet.slang` 在 GPU 上将最多 8 只脚转换成扰动：

- **入水**：浸水比例增加时，按增加量与向下速度产生中心下压、外围隆起的椭圆脉冲。
- **离水**：浸水比例减少时，产生方向相反、强度较弱的回填脉冲。
- **水中拖动**：水平扫掠的定向扰动乘以浸水比例；完全离水时为零。
- **静止支撑**：位置、浸水程度不变，扰动严格为零。

入水/离水响应在相交过程的多个物理子步内平滑释放，强度与浸水比例的变化有关，不是每帧固定加一次冲击。椭圆影响范围略大于脚掌，并根据网格尺寸进行平滑。所有角色的脚部贡献先相加，再统一推进水面，不需要 CPU 读回纹理。

这是单向、面向视觉的水体耦合：不求解真实排水体积、不反作用于角色，也不把脚作为水流绕行的动态固体边界。入水判断使用静止水位，避免经过支撑脚的波纹反复触发冲击；因此不追踪动态波峰与脚底的精确接触。深水中一直浸没的小腿交互不在本版范围内。

## GPU 模拟与渲染

默认 `768 × 768` 网格覆盖 `24 × 24` 米，即每格 3.125 cm。世界范围为 `[-12,12] × [-12,12]`，映射为：

```text
uv = world.xz / extent + 0.5

四人双足动画 → 8 只脚上一/当前姿态 → GPU 入水 + 离水 + 拖动
                                          ↓
水域遮罩 → simulate(state A → state B) → 交换 A/B
                                          ↓
                           高度梯度 → 法线 → Slang 水面渲染
```

| 资源 | 格式 | 含义 |
| --- | --- | --- |
| State A / B | RGBA32_FLOAT | 高度偏移（m）、竖直速度（m/s）、视觉活动度、预留 |
| Mask | R32_FLOAT | 1 为水域，0 为岸和岛屿 |
| Display | RGBA32_FLOAT | 已完成显示转换的颜色 |

使用五点 Laplacian 和先速度后高度的 symplectic Euler：

```text
v_next = (v + dt × c² × laplacian(h) + foot_forcing + impulse) × exp(-damping × dt)
h_next = h + dt × v_next
```

子步为 `min(1/120, 0.6 × dx / (sqrt(2) × c))`。改变波速会自动调整子步，窗口缩放和镜头移动均不改变世界空间模拟。窗口卡顿最多补 0.1 秒。

岸边用镜像高度（Neumann）反射，干燥单元清零，RT 外沿设 1.8 m 吸收带。`--open-water` 可切换全湿网格。默认湖泊世界尺寸固定，`--extent` 仅修改模拟覆盖范围。

## 世界空间折射与反射

摄像机射线与 `Y=0` 的水面参考平面相交，模拟高度梯度决定该位置的法线，再分出水下折射射线与空气中的反射射线。**这里没有屏幕空间 ray marching，也没有硬件 RayQuery / 加速结构。**

- **折射**：用 `refract(incident, normal, 1 / IOR)`，默认水折射率 1.333。对水下脚掌和水底求最近交点，脚掌轮廓与底部纹理都会沿真实折射方向改变可见位置。
- **求交**：脚掌和两处原有岛屿上的岩石代理采用解析椭球求交。平坦水底直接求平面交点；岸边坡底按世界空间高度函数搜索首个交点区间并二分求根，不读取屏幕深度。
- **吸收**：按折射射线实际行进距离计算 `T = exp(-sigma × distance)`。默认 RGB 吸收系数为 `(6, 1.4, 0.7) × Absorption`，单位是每米；这些是可调美术参数。另有简化的水体散射颜色。
- **反射**：反射射线查询同一组场景几何，未命中时采样程序化天空与云。即使脚掌不在主视图内，也可以出现在水面倒影里。
- **Fresnel**：用非偏振介电质 Fresnel 公式分配反射和透射，正常入射的水面反射约 2%，掠射角逐渐增强。
- **粗糙度与太阳**：局部/天空反射采用稳定的五射线锥形滤波近似模糊；太阳使用 GGX 分布与 Smith 遮蔽项。环境天空不再含太阳盘，避免和直接太阳项重复计算。太阳方向可调。
- **遮挡**：只有水面之前的实体能直接覆盖水面；水下脚掌只通过折射光路显示，移除了原先从主视线叠加半透明脚掌的做法。水底还有物体投下的直接光阴影。

`--no-refraction` 只取消弯曲，保留吸收，用于检查轮廓变化；`--no-reflection` 显示全权重透射，便于对比。IOR 设为 1 时应同时消除折射弯曲与 Fresnel 反射。

边界仍是参考平面，水面几何没有位移；放大的着色法线在极端坡度处会受限，以避免将反射射线送到未实现的第二次水面交点。当前只有一次水面分光，不做多次折反射、严格微表面透射积分或真实焦散。五射线反射滤波、太阳有限宽度、环境和水体散射均为实时近似。程序化焦散和局部活动度泡沫仍属于视觉辅助效果。

NPZ 中 `state` 为 `(N,N,4)` float32，第一维对应 Z，第二维对应 X，另含 `mask`、`extent`、`time`。`optics` 为显示分辨率的 RGBA32 数据：Fresnel 权重、水下光程（m）、折射命中 ID、反射中心射线命中 ID。ID 0 表示水底/天空，1/2 表示主角左右脚，3/4 表示岩石，5–10 表示 NPC 的 6 只脚；前景物体覆盖区域和模拟调试视图置零。常规 PNG 已编码，勿重复 gamma 转换。

## 文件与后续接入

- `gait.py`：程序化步态、支撑脚锁定、停步收脚和浅水底面采样。
- `crowd.py`：3 个 NPC 的确定性随机路线、水域避障和独立步态。
- `recording.py`：固定帧率 MP4 导出、编码及帧数/时长验证。
- `test_crowd.py`：随机路线可复现、岸边间距、多脚扰动及折射可见性验证。
- `app.py`：输入、固定时间步、UI、headless / 视频入口。
- `water.py`：SlangPy 资源、双足参数绑定、dispatch、截图导出。
- `shaders/feet.slang`：共享双足数据、椭圆局部坐标、入水/离水/拖动扰动。
- `shaders/simulation.slang`：网格初始化、遮罩与波动求解。
- `shaders/render.slang`：水面、双足代理、投影轮廓与目标落点。
- `shaders/optics.slang`：Fresnel、Beer–Lambert、稳健椭球求交和 GGX/Smith。
- `shaders/scene.slang`：共享岸线与程序化噪声。
- `test_water.py`：步态时序、支撑锁定、停止收脚、悬空无扰动、入水/离水符号、静水、传播耗散、干湿边界、帧率独立性与渲染导出测试。
- `test_optics.py` / `shaders/test_optics.slang`：GPU 光学数值校验、折射光程、脚掌轮廓位移、屏幕外物体反射、粗糙度、同折射率退化情况和岸边求交验证。

接真实角色时，用最终动画/IK 后的脚骨骼姿态替换 `Biped.update()` 的输出，保持每个物理子步的前后位置连续。Python 当前的解析水底也应替换为游戏地形采样。当前 `g_feet[8]` 常量数组用于四人场景；更多角色可扩展为脚部结构化缓冲区并加入空间剔除，或使用交互 RT；水花粒子和小腿代理可以单独补充。

SlangPy 组织方式参考 DDDDGI；运行本项目不需要该仓库。[SlangPy compute shader 文档](https://slangpy.shader-slang.org/en/stable/src/tutorials/compute_shader.html)介绍所用接口；[Chentanez / Müller 2010](https://matthias-research.github.io/pages/publications/hfFluid.pdf)讨论高度场波动方程、SWE 与固体耦合。

光学公式参考 PBRT 的[介电质反射与透射](https://www.pbr-book.org/4ed/Reflection_Models/Specular_Reflection_and_Transmission)和[微表面粗糙度模型](https://www.pbr-book.org/4ed/Reflection_Models/Roughness_Using_Microfacet_Theory)。
